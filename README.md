Rocket League Beta — PS3

An independent PS3 homebrew project inspired by car-soccer games.

Goal

Build an original car-soccer game for PlayStation 3 that can run on compatible PS3 HEN systems.

Planned Features

* 3D arena
* Driveable cars
* Physics-based ball
* Goals and scoreboard
* Local multiplayer
* Original menus and sound effects

Development Plan

1. Research the PS3 homebrew development toolchain.
2. Create a minimal PS3 homebrew application.
3. Build the arena and camera.
4. Add car movement and ball physics.
5. Add goals, scoring, and controller support.
6. Package and test on a compatible PS3.

Important

This is an independent fan project, not an official Rocket League port. It will use original code and appropriately licensed assets.

Status: Planning stage.
